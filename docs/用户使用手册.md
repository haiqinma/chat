# Chat 用户指南

本文档面向 Chat 网页版和桌面版用户，介绍登录、模型令牌、聊天、技能、图片创作、数据同步及常见问题。部署和服务端配置不在本文档范围内。

## 1. 开始使用

Chat 网页版和桌面版使用同一套账户、模型和云端数据。桌面版不是离线应用，登录、模型调用和云端同步仍需连接相应服务。

首次使用建议按以下顺序操作：

1. 打开 Chat 网页版或桌面版。
2. 输入或选择区块链地址并完成登录。
3. 按页面提示完成动态验证码授权。
4. 选择一个可用的 Router 令牌。
5. 新建会话并发送第一条消息。
6. 需要跨设备使用时，在“发现 -> 云端存储”中检查同步状态。

## 2. 登录与账户

### 2.1 区块链地址

区块链地址是 Chat 的账户标识。会话、设置、技能配置和云端数据都按地址隔离。

- 使用同一个地址登录 Web 和桌面版，才能访问同一份账户数据。
- 换一个地址相当于切换到另一个账户。
- 排查账户问题时，应提供完整地址，不要只提供开头或末尾几位。
- Chat 不会要求用户提供钱包私钥或助记词。

### 2.2 动态验证码授权

中心化登录可能要求使用 Authenticator 等应用生成动态验证码（TOTP）。

首次绑定时：

1. 使用 Authenticator 扫描页面上的二维码。
2. 输入当前显示的六位动态验证码。
3. 验证成功后返回 Chat，等待登录和工作区初始化完成。

之后登录时直接输入 Authenticator 中该账户当前显示的验证码，不需要重复扫码。

动态验证码通常每 30 秒更新一次。如果验证失败：

- 等待下一组验证码后重试。
- 确认手机时间设置为自动同步。
- 确认选择的是当前环境和账户对应的验证码记录。
- 不要连续输入已经过期的验证码。

只有服务端重置了 TOTP 密钥、账户解绑，或切换到完全不同的服务环境时，才需要重新扫码绑定。

### 2.3 登录后的初始化

登录成功后，Chat 还需要恢复 Router 令牌和账户工作区，并尝试拉取云端数据。这个过程可能短暂显示加载状态。

如果登录成功但没有进入聊天页面，不要反复重新绑定动态验证码。先检查页面是否提示：

- 正在同步账户数据；
- 尚未选择 Router 令牌；
- Router 令牌过期、禁用或额度不足；
- 云端存储连接失败。

## 3. Router 与模型

Router 为 Chat 提供可用的大模型。一个 Router 令牌决定当前可用的模型、额度和有效期。

### 3.1 选择令牌

首次登录后，如果页面提示没有可用模型：

1. 打开“发现”。
2. 进入“社区 Router”。
3. 在 Router 配置中选择一个可用令牌。
4. 点击刷新模型或重新检查。
5. 返回新建会话页面。

Router 页面会显示当前令牌、可用额度、已使用额度、过期时间和支持的模型。

### 3.2 令牌异常

出现以下状态时，需要在 Router 中处理：

- `未选择`：当前账户还没有选择模型令牌。
- `已过期`：续费或切换令牌。
- `额度不足`：充值或选择其他可用令牌。
- `已禁用`：重新选择有效令牌。
- `未返回模型`：刷新状态，并检查令牌是否具有模型权限。

处理完成后回到 Chat 点击“重新检查”，通常不需要退出登录。

### 3.3 选择模型

不同模型适合不同任务：

- 文本模型：问答、写作、翻译、分析和编程。
- 推理模型：复杂分析、规划和多步骤问题。
- 视觉模型：理解用户上传的图片。
- 图片模型：根据文字生成或编辑图片。
- 实时模型：支持实时语音交互。

页面只会展示当前令牌实际可用的模型。某个技能如果依赖特定模型能力，会在不可用时显示原因。

## 4. 聊天

### 4.1 新建会话

在“新建”页面可以直接开始通用对话，也可以选择一个技能进入特定任务。

通用对话不会自动携带技能专属工具，适合普通问答。不同任务建议创建不同会话，便于查找和控制上下文。

### 4.2 发送消息

在输入框中输入内容并发送。模型回复过程中可以停止生成，之后可以继续提问或重新生成。

为了得到更稳定的结果，建议在问题中说明：

- 要完成的任务；
- 必要的背景信息；
- 期望的输出格式；
- 不能违反的限制。

例如：

```text
请把下面的会议记录整理成行动项，按负责人、任务、截止时间输出表格；无法确认的信息标记为“待确认”。
```

### 4.3 图片和文件

当当前模型支持相应能力时，可以向会话添加图片或文件。发送前确认文件中不包含不应上传的密码、私钥、助记词或其他敏感数据。

如果模型无法读取附件，优先检查：

- 当前模型是否支持视觉或文件输入；
- 文件格式和大小是否受支持；
- 上传是否已经完成；
- 网络和云端存储是否可用。

### 4.4 会话管理

左侧会话栏用于打开、重命名和删除历史会话。搜索功能可以按内容查找历史记录。

删除会话前应确认不再需要其中内容。重要结果可以先导出为 Markdown 或图片。

### 4.5 长对话

长对话会携带历史消息或历史摘要，可能增加消耗，也可能让模型受到旧上下文影响。

遇到以下情况时建议新建会话：

- 已经开始讨论另一个主题；
- 模型持续引用过时信息；
- 只需要处理一次性任务；
- 当前会话上下文已经很长。

## 5. 技能与发现

技能是针对具体任务预设的工作方式，可能包含提示词、模型要求和工具依赖，例如翻译、研究、代码处理或内容创作。

### 5.1 使用技能

1. 打开“发现”。
2. 选择一个技能。
3. 查看技能说明和所需能力。
4. 如有需要，完成模型或工具配置。
5. 点击使用，进入对应会话或工作区。

技能显示不可用时，页面会说明缺少的模型、工具或配置。补齐依赖后再使用，不建议在通用会话中手工模拟无法运行的工具能力。

### 5.2 技能配置

技能可以使用全局模型设置，也可以保存自己的模型配置。修改技能配置只影响使用该技能创建的会话，不会自动改变其他会话。

### 5.3 Web 与桌面版差异

两端共享账户、会话和技能数据，但运行能力可能不同：

- Web 版只能使用部署实例已经提供的服务端工具。
- 桌面版当前不默认运行本地 Shell、Git 或本地 Tool Server。
- 页面显示“当前版本不可用”时，表示该能力没有在当前运行环境启用。

## 6. 图片创作

在新建页面选择“图片创作”，然后选择可用图片模型并输入描述。

描述中可以包含：

- 主体和动作；
- 场景和构图；
- 风格和光线；
- 尺寸或比例；
- 不希望出现的内容。

如果没有可用图片模型，前往“社区 Router”检查当前令牌支持的模型。生成完成后可以下载图片或继续调整描述。

## 7. 云端同步

云端同步用于在同一账户的 Web、桌面端和不同设备之间恢复会话、设置、技能配置等数据。

当前同步是多端快照合并，不是多人实时协作。

### 7.1 首次跨端同步

建议按以下顺序验证：

1. 在已有数据的一端登录正确账户。
2. 打开“发现 -> 云端存储”。
3. 点击“检查连接”。
4. 点击“立即同步”，等待成功提示。
5. 在另一端使用相同区块链地址登录。
6. 再次执行“检查连接”和“立即同步”。
7. 回到聊天首页确认左侧会话恢复。

### 7.2 自动同步

启用自动同步后，应用会在启动、关键数据变化、定时检查或页面重新激活时尝试同步。退出应用前，如果刚完成重要操作，可以手动执行一次“立即同步”。

### 7.3 连接正常但没有会话

依次确认：

1. Web 和桌面端登录的是完全相同的区块链地址。
2. 有数据的一端已经成功上传快照。
3. 新设备端的“立即同步”确实成功。
4. 同步完成后已返回聊天首页，必要时重新打开应用。

如果两端检查连接和立即同步都成功，但数据仍不一致，需要联系维护人员检查两端是否使用同一个云端应用空间。普通用户不需要自行修改服务地址。

### 7.4 同步失败时的数据处理

同步失败不等于本地会话已经丢失。不要立即清除应用数据或重置所有设置。先保留错误截图，检查网络后重试。

在多个设备同时编辑同一会话时，应先在一端完成同步，再切换到另一端，减少冲突。

## 8. 设置与数据安全

设置页面可以调整主题、字体、默认模型、历史消息数量、模型参数、语音能力和同步选项。

普通用户通常只需要修改：

- 默认模型；
- 主题和字体；
- 历史消息数量；
- 自动同步；
- 实时语音或文本转语音。

“重置所有设置”和“清除所有数据”是不同操作：

- 重置设置：恢复默认配置。
- 清除所有数据：删除当前设备上的会话和设置。

执行清除前，先确认云端已有最新快照，并导出重要内容。

安全注意事项：

- 不向任何人提供钱包私钥、助记词或 TOTP 二维码。
- 不在聊天中发送长期有效的 API Key、访问令牌或密码。
- 不在不可信设备上保持登录。
- 截图反馈问题前遮盖令牌、完整授权信息和敏感文件内容。

## 9. 桌面版

桌面版支持原生窗口、剪贴板、文件保存、通知和应用更新等能力。

### 9.1 安装

macOS 用户打开 `.dmg` 后，将 Chat 拖入“应用程序”目录，再从“应用程序”启动。测试包可能由维护人员直接提供，正式发布包应具有有效签名。

Windows 和 Linux 的安装格式取决于发布版本，请使用官方发布页提供的安装包。

### 9.2 更新

收到更新提示时，保存当前工作并确认重要数据已经同步，再执行更新。更新应用通常不会删除用户数据，但重要内容仍建议定期同步或导出。

### 9.3 桌面版无法登录

如果 Web 可以登录但桌面版提示 `Load failed`：

1. 确认本机网络正常。
2. 完全退出并重新打开 Chat。
3. 保留包含错误文字的截图。
4. 联系维护人员检查登录服务是否允许桌面应用访问。

不要把 `http://tauri.localhost/...` 回调地址改成登录服务地址；它是桌面应用内部接收授权结果的固定地址。

## 10. 常见问题

### 登录验证码一直失败

等待新验证码、确认手机时间自动同步，并检查 Authenticator 中选择了正确记录。不要重复使用上一组验证码。

### 登录成功但页面没有进入聊天

观察是否正在恢复工作区、同步数据或等待选择 Router 令牌。进入“社区 Router”检查令牌和模型状态。

### 提示没有可用模型

打开“发现 -> 社区 Router”，选择有效令牌并刷新模型。令牌必须有额度且未过期。

### 模型回复中断或请求失败

检查网络和 Router 状态，然后重试。重复失败时记录使用的模型、发生时间和完整错误信息。

### Web 有会话，桌面端没有

在 Web 端先执行一次立即同步，再在桌面端使用同一地址登录并立即同步。两端必须使用同一个账户和云端应用空间。

### 换设备后设置没有恢复

确认旧设备已经上传最新快照，新设备已完成下载和合并。同步失败时不要先清空旧设备数据。

### 技能点击后不可用

查看技能页面列出的模型和工具依赖。当前版本没有对应运行能力时，需要更换可用技能或由维护人员启用所需能力。

### 如何反馈问题

提供以下信息可以加快定位：

- 使用 Web 版还是桌面版；
- 操作系统和应用版本；
- 问题发生时间；
- 登录账户地址，可遮盖中间部分；
- 从开始操作到出现错误的步骤；
- 完整错误文字和截图；
- Web、Router、云端存储中哪些功能正常、哪些失败。

不要在问题反馈中提供私钥、助记词、TOTP 二维码、完整令牌或密码。
